## What is a virtual research system?

A virtual research system is a server that runs on RCS infrastructure but behaves like your own dedicated machine that you can connect to as you need it. We can allocate hardware, software and memory based on the need of the project.

## When it's a good fit

- _Your project doesn't run well in parallel, or needs a cluster architecture_
- _A web service or database your project needs to keep running_
- _Software that needs administrator access, or doesn't work on the shared cluster_
- _A dedicated environment for a course or lab_

## What's available

_RCS has a series of virtual machine hosts with hundreds of cores, separated GPUs, and up to 1.5TB of memory_

## How to request one

[Open a ticket](https://request.fandm.edu) and search for Research Computing. Tell us what you'd like to run and roughly how long you'll need it, and we'll follow up to work out the details.

Not sure whether you need a virtual system or the [campus cluster](../../services/hpc/)? Ask us. That's what we're here for.
