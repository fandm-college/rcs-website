## Posit Workbench (RStudio)

Posit Workbench gives students a familiar RStudio interface for R, with packages, data analysis, visualization, and reproducible reports, all in a managed environment. Faculty use it for statistics and data-analysis courses and workshops.

Posit Workbench is intended for classroom and instructional use only, and isn't available for research computing. If you'd like to use R for a research project, [contact us](mailto:dorc@fandm.edu) and we'll help you find the right option.

You'll need a Posit Workbench account before you can log in. [Request one](https://request.fandm.edu/TDClient/299/Portal/Requests/Service/6651/General-Research-Computing-Consultation) and we'll set it up and tell you where to go.

Common tasks:

- Request a Posit Workbench account
- Use RStudio in a managed environment, with nothing to install on your own computer
- Request a course setup for your class
- Install the R packages your course needs
- Troubleshoot R projects

## WeBWorK

WeBWorK runs online problem sets with automated grading for mathematics and other quantitative courses. Students get immediate feedback on each answer, and you spend less time grading.

Common tasks:

- Request a WeBWorK course
- Manage problem sets
- Help students get access
- Troubleshoot assignments

## Getting a course set up

[Request a course](https://request.fandm.edu/TDClient/299/Portal/Requests/Service/6651/General-Research-Computing-Consultation). Tell us the course, the semester, and whether you need Posit Workbench, WeBWorK, or both. Please reach out at least two weeks before your class starts!
